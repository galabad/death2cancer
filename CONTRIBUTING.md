# Contributing

Contributions are welcome for reproducibility tooling, source verification, documentation, and public-data workflow improvements.

Before opening a pull request:

1. Use stable source URLs or identifiers (DOI, PMID, OpenAlex, DrugBank/ChEBI/PubChem identifiers where licences permit).
2. State retrieval date, model or population, evidence tier, limitations, and contrary evidence.
3. Do not add patient-identifying data, controlled-access data, credentials, or unpublished confidential material.
4. Do not make treatment, dosing, or patient-specific claims.
5. Keep machine-readable records separate from narrative conclusions and preserve negative results.

For material data-access or methodological questions, open an issue with the proposed source, licence/access tier, and intended analysis.
